# Dataset

## Dataset name

GSE62191

## Source

NCBI Gene Expression Omnibus (GEO)

## Description

Gene-expression profiles from frontal-cortex samples from healthy
controls, individuals with bipolar disorder and individuals with
schizophrenia.

## Data access

The dataset can be obtained from the NCBI GEO database:

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE62191

The dataset is not currently stored in this repository.
