
# AI assistance declaration
LLMs were used as search engines for researching ML methods that could be applicable to this project (such as elastic net feature selection) and for summarising papers and reported workflows. They were also used to error-check code I wrote, for help in resolving errors I came across, and to review markdown cells for incorrect phrasing or inaccuracies, but all code and markdown cells were written myself. Any suggestions made by an LLM regarding the above were thoroughly reviewed and validated by myself before implementation.
